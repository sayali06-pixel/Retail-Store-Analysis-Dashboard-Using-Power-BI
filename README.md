# Retail Store Sales Analysis Dashboard Using Power BI

## 1. Project Overview

A dynamic and interactive Power BI dashboard developed to analyze retail store sales performance, profitability, products, customers, and regional sales trends. The dashboard provides meaningful insights through interactive visualizations and KPIs to help users understand business performance and make data-driven decisions.

---

## 2. Short Description / Purpose

The Retail Store Sales Analysis Dashboard is a visually interactive Power BI report designed to analyze sales and profit performance across different products, categories, regions, and time periods. The dashboard helps identify top-performing products, high-revenue regions, monthly sales trends, and overall business performance.

The dashboard is intended for store managers, business analysts, and decision-makers who want to monitor sales performance and identify areas for improvement.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Main data visualization and dashboard development platform.
* 📁 **Power Query** – Used for data cleaning, transformation, formatting, and preparation.
* 🧠 **DAX (Data Analysis Expressions)** – Used to create calculated measures, KPIs, and business calculations.
* 🔗 **Data Modeling** – Used to establish relationships between the Sales Table and Product Table for effective analysis.
* 📄 **Microsoft Excel** – Used as the primary source format for the retail sales dataset.
* 📈 **Power BI Visuals** – Used to present KPIs, charts, trends, category analysis, regional performance, and product rankings.

---

## 4. Data Source

The retail sales dataset was provided in Excel format and contains information related to retail transactions and products.

The dataset consists of a **Sales Table** and a **Product Table**, which contain information such as sales amount, quantity, unit price, products, categories, customers, regions, and dates.

The data was cleaned and validated before being used for dashboard development. Data types, date fields, duplicate records, missing values, and sales calculations were checked to ensure data quality and accuracy.

---

## 5. Features / Highlights

### • Business Problem

Retail businesses generate large amounts of sales data, but analyzing this data manually can make it difficult to understand overall performance, identify successful products, compare regions, and track sales trends over time.

### • Goal of the Dashboard

The main goal of the dashboard is to transform raw retail sales data into meaningful and easy-to-understand business insights using Power BI.

### • Key KPIs

The dashboard provides important performance indicators such as:

* **Total Sales**
* **Total Profit**
* **Total Orders**
* **Average Sales**
* **Profit Margin %**

### • Key Visuals

The dashboard includes visualizations for:

* **Sales by Category** – Compares sales performance across different product categories.
* **Sales by Region** – Identifies regions generating higher revenue.
* **Monthly Sales Trend** – Shows how sales change over different months.
* **Top 10 Products** – Identifies the products contributing the most sales.
* **Bottom 10 Products** – Highlights products with comparatively lower sales performance.

### • Business Impact & Insights

The dashboard helps management quickly identify high-performing products, high-revenue regions, profitable areas, and monthly sales patterns. These insights can support better inventory planning, product decisions, regional strategies, and overall business performance monitoring.
